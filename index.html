01 / AI AGENT PRODUCT

StaySim Studio

面向建筑与公共空间的行人模拟工作台。导入规范化二维 DXF，生成 YAML 场景；自然语言需求由 Agent 解析并形成待确认计划，确认后运行 StaySim 模拟、校验并展示结果。A pedestrian-simulation workspace for built environments. It imports a constrained 2D DXF, creates a YAML scene, converts natural-language requests into a reviewable plan, then runs and checks a StaySim simulation after human approval.

02 / INTERACTIVE WEB PRODUCT

纠结擂台Dilemma Arena

把两个日常选项变成角色，让它们完成一场六回合较量。用户输入理由，系统按本地规则生成角色与技能，最后可以接受判决，也可以“我不服”改判。A playful mobile-first experience that turns two everyday options into characters for a six-round battle. Local rules generate traits and skills from the user's reasons; the final verdict can be accepted or overturned.

StaySim 把场景检查、需求解析、人工确认、执行与结果回溯串成闭环；纠结擂台用游戏机制让抽象的“做决定”变得可操作。两者都从最小可用流程开始，再用测试和实际体验检验。StaySim connects scene validation, request parsing, human approval, execution, and result review. Dilemma Arena makes an abstract decision tangible through play. Both began with a focused MVP and were checked through tests and hands-on use.

说明：StaySim 的公开验收覆盖规范化 DXF 与规则模式模拟；这里不把离线工作流测试等同于 LLM 行为准确率，也不把静态展示页称为在线 Agent。Scope: StaySim's public acceptance covers normalized DXF and rule-mode simulation. Offline workflow tests are not LLM behavior accuracy, and this static page is not presented as a live Agent.
